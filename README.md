# JnM Gourmet Cuisine

Public website for **JnM Gourmet Cuisine** — a neighbourhood restaurant in Graceville, San Jose del Monte, Bulacan.

## Live site (GitHub Pages)

1. Open the repo **Settings → Pages**
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)`
4. Save — the site will be at:

`https://jstlikeme.github.io/jnm-gourmet-cuisine/`

## Contents

- `index.html` — landing page (hero, about, menu, gallery, contact)
- `styles.css` — branding styles
- `assets/` — menu photos from social flyers

## Editing the menu

Update the menu cards in `index.html` (search for `menu-grid`). Keep prices in ₱ and avoid inventing items that are not offered.
